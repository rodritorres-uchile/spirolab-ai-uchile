# Validación

Esta carpeta está destinada a comparar el motor con calculadores y equipos validados.

Cada caso debe registrar:

- ecuación de referencia y versión;
- edad, sexo, talla y grupo de referencia;
- valores esperados y calculados;
- tolerancia aceptada;
- fuente del vector de prueba.

La versión actual es educativa y no debe utilizarse para diagnóstico clínico.
