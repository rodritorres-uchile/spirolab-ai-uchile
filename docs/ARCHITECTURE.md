# Arquitectura

- `src/core/reference-engine.js`: referencias seleccionables.
- `src/core/pathology-engine.js`: perfiles fisiopatológicos.
- `src/core/curve-engine.js`: CurveEngine 2.1, PEF redondeado y excavación por enfermedad.
- `src/core/interpretation-engine.js`: árbol interpretativo por LLN/z-score.
- `src/core/quality-engine.js`: criterio CVIF–CVF.
- `src/ui/`: plantilla y renderizado SVG.
- `tests/`: comprobaciones automáticas sin dependencias.
- `dist/`: versión construida.
