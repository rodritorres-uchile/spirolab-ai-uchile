# SpiroLab AI-UCH v0.5.3

Corrección del motor morfológico flujo-volumen.

- Los patrones obstructivos usan anclajes específicos de flujo al 25, 50 y 75% de la CVF.
- Asma, bronquitis crónica, bronquiectasias, mixto probable y enfisema presentan excavación progresivamente mayor.
- El solver de VEF1 queda limitado para que no pueda enderezar la rama descendente.
- Los patrones restrictivos permanecen estrechos y sin excavación obstructiva artificial.
